<h1 align="center">
Mintdows
</h1>

Mintdows es un script de automatización y personalización para transformar **Linux Mint (Cinnamon)** en un entorno familiar estilo **Windows 10**, diseñado específicamente para mejorar la experiencia de uso en trabajo profesional.

## Características
* **Interfaz Familiar:** Temas visuales, paquete de íconos y barra de tareas configuradas al estilo clásico de Windows 10.
* **Kit de Herramientas:** Instalación automatizada de utilidades esenciales (OnlyOffice, LocalSend, PDF Arranger, VLC).
* **Utilidades del Sistema:** Integración de CopyQ (historial de portapapeles) y Emote (menú de emojis).
* **Mantenimiento Simple:** Incluye un script de actualización automatizado con un solo clic.

## Instalación
1. Instala Linux Mint (Cinnamon), puedes hacerlo desde [aquí](https://linuxmint.com/download.php)
2. Abre la terminal y clona el repo
```bash
git clone https://github.com/iliekcatsss/mintdows.git
```
3. Ejecuta el archivo de instalación
```bash
cd mintdows && chmod +x install.sh update.sh && ./install.sh
```
4. ¡Listo! Disfruta tu experiencia con Mintdows
